# MapleDash Windows Mono DLL – full C# reconstruction

Goal: convert the **entire** user-provided Unity Mono `Assembly-CSharp.dll` to readable C# using a real IL decompiler (`ilspycmd`), instead of claiming that a handful of hand-converted methods constitute complete source code.

## What is in this directory

- `inputs/`: 41 base64 segments of XZ-compressed `Assembly-CSharp.dll` plus a SHA-256 manifest. It is **not** the full game data pack.
- `scripts/reassemble.py`: deterministic byte-perfect recovery with SHA-256 verification; it never executes the binary.
- `scripts/audit.py`: inspection of output with counts and limits.
- `DecompiledCSharp/`: **generated by GitHub Actions if the workflow succeeds**. C# and `.csproj` from ILSpy, not a reconstructed Unity Editor project.
- `.github/workflows/mapledash-complete-decompile.yml`: performs the whole decompilation and commits results on this isolated branch.

## How to run yourself

1. Reassemble: `python scripts/reassemble.py`
2. Install .NET SDK and `dotnet tool install --global ilspycmd`.
3. Run: `ilspycmd -p -o DecompiledCSharp tmp/Assembly-CSharp.dll` (project mode), falling back to `ilspycmd -o DecompiledCSharp tmp/Assembly-CSharp.dll` if needed.
4. Run `python scripts/audit.py`.

The original Unity project files, user-made prefabs/scenes, source comments, Unity asset packs, platform-specific native libraries, and proof of functional compilation are **not** recovered by decompiling the assembly. Network server functionality needs separate testing and likely engineering work. Do not assert it is already a working standalone multiplayer server.
